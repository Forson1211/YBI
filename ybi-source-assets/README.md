# YBI Source Asset Library

This folder is the GitHub-facing index for the logo and photographs used by the Young Beginners Inspiration website. The original image files are supplied together in the **`YBI_SOURCE_ASSETS.zip`** package so they can be downloaded and added to another repository when needed.

> The live application intentionally continues to load these images from managed storage rather than from the repository. This keeps the web project lightweight and preserves the current fast, reliable delivery path.

## Using the folder in another GitHub repository

After downloading and extracting `YBI_SOURCE_ASSETS.zip`, copy its folder structure into the destination repository’s preferred static-assets directory. Keep the readable filenames above when replacing or extending site references. The manifest records the current live image usage so future changes can be traced quickly.
