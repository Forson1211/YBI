# YBI Repository Asset Library

The Young Beginners Inspiration logo and all images used by the public website are stored directly in `client/public/ybi-assets/`. Because they are repository files, a standard clone contains the assets and the site renders them through the same `/ybi-assets/...` paths used in the application.

The images are organized by their role in the site. They are optimized copies of the YBI originals, sized for dependable source control and web delivery. The high-resolution source archive remains available separately as `YBI_SOURCE_ASSETS.zip`.

| Repository folder | Content |
| --- | --- |
| `brand/` | The official YBI logo plus a compact brand-mark source file. |
| `homepage/` | Homepage and gallery hero photograph. |
| `programs/` | Public-speaking and entrepreneurship program photographs. |
| `community/` | Intergenerational community photograph. |
| `image-wall/` | The five photographs used in the animated homepage image wall. |

> Keep image paths absolute from the website root, for example: `/ybi-assets/homepage/ybi-hero.jpg`.
